# Elpriser - Analysverktyg

Detta program hämtar aktuella elpriser och låter användaren analysera dagens priser.

## Upplevelse av Java

Jag tycker att det var kul att jobba med Java. Dock så var det väldigt svårt att komma från det löst typade JavaScript. Men jag gillar känslan av kontroll och att det känns mer robust. 

Sen har det varit svårt att ställa om tänket till OOP. Men för varje steg blir det lättare att greppa.

Sen ska det tilläggas att den här uppgiften programmeringsmässigt kan likställas med den största gruppuppgiften vi hade förra året. Och då hade vi flera veckor på oss. Men jag gillar att vi höjer nivån. Vi är ju här för att lära.
